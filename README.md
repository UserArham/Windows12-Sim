# Windows 12 Simulator (Web)

A fun **browser-based Windows 12 simulator** built with **Next.js** and JavaScript.  
You can open apps like **Calculator** and **Notepad**, drag windows, and explore a **Windows-like desktop experience** — all in your web browser!  

This project is designed to work entirely **online**, so no need for C++ or local compilation. Perfect for experimenting on **GitHub Mobile**.

---

## Features

- 🖥️ Windows-style desktop with wallpaper  
- 📁 Desktop icons  
- 🪟 Draggable windows (Notepad, Calculator)  
- 🧮 Calculator app using JavaScript  
- 📌 Taskbar with open windows  
- 💻 Fully browser-based — works on mobile and desktop  

---

## How to Use

1. Open the deployed app in your browser (or run locally with Next.js).  
2. Double-click a desktop icon to open an app.  
3. Use the **X button** to close windows.  
4. Explore the taskbar and open multiple apps at once.
